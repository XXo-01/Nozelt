# Интерфейс Windows — 04.10.2026

Базой остаются общие Android-экраны и существующие модели. Windows получает
собственную плотность, Segoe UI, адаптивные колонки и постоянно доступную
навигацию. Запущенная desktop-копия и её TUN при этой работе не заменяются.

## Изменения

- Логотип слева 48×48, надпись 32 px. Убрана закруглённая маска, добавлен
  прозрачный запас в самом PNG; контур больше не обрезается.
- Главная: единый заголовок, карточки и статистика с адаптацией к размеру
  окна и увеличенному тексту. Повторного бренда над содержимым нет.
- Профили: подписанная кнопка добавления, читаемые чипы протокола/задержки,
  локальные флаги, привязанное к кнопке меню действий Windows.
- Маршрутизация: категории в две колонки на широком окне, действия редактора
  в три колонки. На узком окне — прокрутка одной колонки. Общий формат правил
  и применение Android/Windows не меняются.
- Подключения: строки программ примерно 68 px при стандартном размере текста,
  без прежнего большого внутреннего поля; раскрытие сохраняет состояние.
  Иконки извлекаются из EXE работающего процесса в отдельном нативном потоке.
  Кэш в памяти ограничен 128 именами; успешные результаты живут 30 минут,
  недоступные повторяются через 30 секунд. Нет обращения к PATH, запуска EXE
  или скачивания иконок. Системные/завершившиеся процессы получают заглушку.
  Одноимённые процессы сгруппированы; их значок берётся из первого доступного
  процесса с этим именем. Учёт трафика по-прежнему относится к активным потокам.
- Логи: контрастные уровни, Consolas, пустые результаты поиска, масштабируемые
  колонки времени и уровня. При переходе между страницами снимается фокус
  предыдущего поля ввода.
- Настройки: одна колонка при любой ширине окна;
  согласованные разделители, кнопки, диалоги и редакторы ограниченной ширины.
  Неизвестная проверка Windows kill switch теперь показана нейтрально.

## Вторая итерация

- Подтверждена причина исчезновения навигации при уменьшении окна:
  `_RenderSegmentedButton` получал бесконечную высоту при переключении
  направления сегментов. Переключатель теперь горизонтальный в обоих режимах
  панели и имеет конечную высоту 44 px. Навигация уплотняется при малой высоте,
  все шесть пунктов доступны при 720×520, в том числе с текстом 125%.
- Регрессия проверена последовательными изменениями ширины 1180 → 720 →
  1180 → 959 → 960 → 720. Снимки самой панели снимаются с сохранённых
  слоёв без принудительной перерисовки.
- У тихого запуска удалено пояснение. Надпись Nozelt увеличена с 30 до 32 px,
  размер значка сохранён.
- Главная в узком окне располагает подключение и сервер/задержку рядом;
  маршрутизация идёт отдельной строкой. При увеличенном тексте используется
  вертикальная раскладка с прокруткой. Заголовок профиля маршрутизации и
  кнопка добавления в узком окне разделены, чтобы не теснить друг друга.
- В поиске логов появилась очистка; поиск GeoIP показывает пустой результат.
  Чипы GeoIP получили спокойную рамку и фон. Длинные адреса соединений
  ограничены по высоте, названия программ и обрезанные значения настроек
  доступны в подсказках.

## Третья итерация

- У сегментов Windows отключён дополнительный невидимый tap-target padding:
  `MaterialTapTargetSize.shrinkWrap` сохраняет заливку до рамки при ограниченной
  высоте. На боковой панели остаётся 44 px, без чёрной полосы снизу.
- Все Flutter-подсказки Windows имеют тёмный фон, светлый текст и спокойную
  рамку. Добавлены снимки подсказок навигации и версий.
- Добавление профиля маршрутизации — акцентная кнопка справа от названия
  раздела, в том числе при минимальном окне. Короткая подпись «Добавить профиль»
  оставляет место заголовку; полное назначение есть в подсказке.
- Категории правил идут по две в строке от ширины содержимого 500 px.
  Минимальная высота desktop ListTile уменьшена с 60 до 48 px; у категорий
  убраны большие внутренние отступы. Плотность Android сохранена.
- Настройки остаются одной колонкой на широком и узком окне.
- Поиск подключений и группировка всегда находятся в одной строке одинаковой
  высоты: 38 px при обычном тексте, с увеличением при масштабировании шрифта.
  Утонщены поиск логов, поля ввода и desktop-кнопки.
- Версия под надписью Nozelt получила дополнительный верхний отступ 4 px.
- Из добавления профиля Windows убраны User-Agent, пояснения названия/URL,
  подсказка автоматического ядра, пояснение ссылок и повтор имени файла.
  Автоматический выбор HTTP-заголовка для загрузки подписок и сохранённые
  данные существующих профилей продолжают работать.

## Трей

Полностью удалена owner-draw реализация. Используются CreatePopupMenu,
AppendMenuW и TrackPopupMenu с системными шрифтами, подменю и отметкой режима.
Тёмная тема включается через системный механизм UxTheme, следующий настройке
темы приложений Windows. Настройки ОС не записываются. Есть проверка версии
Windows ≥ 10.0.18362, наличия функций и режима высокой контрастности.
На неподдерживаемой системе остаётся обычное нативное меню.

API включения тёмных Win32-меню не публичный: такой подход также используется
в [Microsoft PowerToys ZoomIt](https://github.com/microsoft/PowerToys/blob/main/src/modules/ZoomIt/ZoomIt/Utility.cpp).
Поэтому гарантировать одинаковый вид на всех будущих версиях Windows нельзя.
Иконки используют документированные
[QueryFullProcessImageNameW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-queryfullprocessimagenamew)
и [ExtractIconExW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-extracticonexw).
