# Редизайн Windows UI — 20 октября 2026

Ориентир — Android-версия; фирменный cyan и навигация Nozelt сохранены. Изменения касаются Windows; на Android по просьбе пользователя изменился только значок «Глобально» на главной (остальные Android-эталоны побайтно совпадают с копией до правок).

## Общая сетка

- Все страницы Windows используют одну колонку: `NozeltLayout.desktopColumnMaxWidth` = 1040, поля `desktopGutter` = 32, верхний отступ 28. Колонка центрируется, поэтому заголовки и карточки не «прыгают» при переходе между вкладками и при любой ширине окна.
- `NozeltPageInsets` отдаёт отступы колонки. Скроллируемый список остаётся во всю ширину, отступы передаются в его `padding`: колесо мыши работает и в боковых полях.
- Навигатор оболочки больше не ограничен по ширине; `NozeltEditorBody` на Windows ничего не ограничивает, ширину задают страницы.
- Подстраницы на Windows используют `NozeltDesktopAppBar`: «назад», заголовок 22 и действия выровнены по краю колонки; вкладки DNS/TUN начинаются от края колонки. Android продолжает использовать прежний `AppBar`.
- `NozeltPageSaveBar` на Windows выравнивает кнопки по правому краю колонки.
- Токены Windows: радиусы control/card/overlay 12/18/14, минимальная высота кнопки 40.
- Тёмная палитра Windows совпадает с Android (AMOLED-чёрный фон #05070A, карточки #10141A); отдельные серые desktop-цвета удалены.
- Редактор правил (Прокси / Напрямую / Блокировать) на Windows — три столбца от ширины 480 при обычном тексте.
- Самодельный значок щита (`NozeltShieldIcon`) больше не используется: «Глобально» — глобус, «Через прокси» — `Icons.verified_user_rounded`.

## Оболочка и главная

- Боковая панель: 224 px (76 в компактном режиме), единые отступы 16, пункты 44 px. Блок версий компонентов убран из панели; он доступен в подсказке логотипа и в Настройки → О приложении.
- Главная — один столбец при любой ширине, каждый блок на своей строке, как на Android: кнопка подключения (без поясняющей подписи), сервер, задержка, трафик, маршрутизация. Две колонки пробовали и отказались: оставалось много пустого места.
- Трафик — две растянутые плитки «Загрузка» и «Отдача»: слева текущая скорость, справа «Всего» за сессию. Единицы локализованы (МБ/с), как на Android; так же и в «Подключениях».
- Все карточки главной: отступ 12, значок в квадрате 40 с тонированным фоном.
- Переключатель «Глобально / Правила» везде в одном порядке (как на главной); в узкой боковой панели он вертикальный. Пункты меню и переключатель — 40 px.
- Плитки соединений и времени убраны: время показано в кнопке, соединения — на вкладке «Подключения».
- Кнопка подключения на Windows — отдельный вариант (`_DesktopPowerButton`): тёмный круг в тонком кольце; выключено — серое кольцо, переход — вращающаяся дуга, подключено — кольцо с градиентом cyan→синий и мягким свечением; время подключения 15 px. Android-кнопка не изменилась.
- Значки строк в настройках и маршрутизации голубые, как на Android; кнопки меню «…» серые, как остальные кнопки-значки.
- Заголовок диалогов на Windows 20 px; «Добавить профиль» маршрутизации — вторичная кнопка, чтобы не спорить с главной кнопкой страницы; «Параметры подключения» в настройках прокси — обычный заголовок раздела.

## Современный стиль (21 октября)

- Боковая панель — плавающая скруглённая карточка с отступом 12 от краёв окна и лёгким голубым оттенком сверху. Выбранный пункт — капсула с градиентом, тонкой голубой рамкой и мягким свечением.
- Кнопки на Windows — капсулы; у основной кнопки мягкая голубая тень. Кнопки-значки круглые.
- Сегменты — капсула без рамок и разделителей, выбранный сегмент залит. Переключатель режима в боковой панели — капсула.
- Радиусы Windows: control 14, card 22, overlay 18. Карточки получили едва заметный блик сверху слева.
- Все элементы выбора на Windows — капсулы как переключатель режима в боковой панели: `NozeltSegmentedControl` рисует `NozeltPillTrack` (дорожка-капсула, выбранный пункт — залитая капсула с тонкой голубой рамкой и мягкой тенью), вкладки DNS/TUN выбираются такой же капсулой, выбранный сервер обведён голубой рамкой вместо боковой полосы.
- `NozeltTokens.glow` — фирменный cyan для оттенков и свечения в обеих темах (тёмный primary светлой темы давал грязный оттенок). Им окрашены боковая панель, выбранный пункт, карточки и подсветка за кнопкой подключения.
- Значки на карточках главной — `NozeltIconBadge`: градиент цвета значка с тонкой рамкой того же оттенка.
- Кнопка подключения в обеих темах использует фирменный cyan (`glow`) и синий; в светлой теме только надпись чуть темнее для читаемости.
- Поля ввода на Windows залиты цветом страницы (чёрные в тёмной теме, белые в светлой) с тонкой рамкой. Поля поиска и фильтр логов — капсулы (`nozeltSearchDecoration`).
- Метки (протокол, задержка, теги GeoIP, счётчики правил, данные соединений) — капсулы. Кнопка «назад» на подстраницах — круглая, с рамкой.
- Основные кнопки (Сохранить, Добавить профиль) — тонированная капсула с голубой рамкой и мягкой подсветкой вместо сплошной заливки. Кнопки Отмена/Сохранить внизу подстраниц — в одной плавающей капсуле, без разделительной линии.
- Наведение на строки списков — капсула (ListTile shape), меню без пустых полос сверху и снизу (menuPadding 0).
- Кнопки пинга, обновления подписки и «…» на странице прокси и обновления задержки — круглые с тонкой рамкой (`nozeltOutlinedIconStyle`).
- Подписка: описание сразу под названием по центру; трафик с тонкой полосой прогресса, дата окончания справа, Telegram — капсула с белым/чёрным значком по теме.
- Значки-акценты на Windows фирменного cyan в обеих темах (`nozeltIconAccent`); текст в светлой теме остаётся тёмно-бирюзовым ради контраста 4.5:1.
- Главная в низком окне (меньше 600 px): кнопка, сервер и задержка заполняют первый экран, трафик начинается ниже края, без обрезанной полосы.
- Если отключение длится дольше 15 секунд, на кнопке пишется «Ждём остановки ядра…».
- Android не изменялся; если стиль понравится, его можно перенести.
