# Скругление интерактивных состояний — 1.0.0+37

## Причина и исправление

Скруглённая рамка Material сама по себе не обрезает ink. В Flutter 3.41
`PopupMenuThemeData.shape` задаёт форму меню, а `PopupMenuButton.clipBehavior`
по умолчанию равен `Clip.none`. Подсветка первого/последнего пункта могла выходить
за контур. Карточки без общего `onTap` также не имели собственного Material:
вложенные ListTile рисовали ink на внешней поверхности.

- Общий `NozeltPopupMenuButton<T>` сохраняет стандартное меню Flutter, callbacks,
  клавиатуру и фокус; включает `Clip.antiAlias`. На него перенесены все шесть
  мест вызова меню в настройках, профилях и маршрутизации.
- `NozeltSurface` всегда создаёт Material с формой карточки и обрезкой,
  включая группы с вложенными ListTile/SwitchListTile.
- Общие кнопки, Card, Dialog и BottomSheet обрезают содержимое по форме.
  Навигация и карточки правил сохраняют свои формы с явной обрезкой.
- Dropdown используют радиус overlay из токенов: ненулевой borderRadius также
  включает обрезку родного dropdown-route.

Цвета hover не скрыты; обработчики, сохранение, Go/C++, ядра и VPN не менялись.
Все четыре нативных файла ядра/драйвера побайтово совпадают со сборкой +36.

## Проверка

- Основное приложение: анализ без замечаний, полный набор **392 теста** проходит.
- Widgetbook: анализ без замечаний, **9 тестов**, release web без внешнего CDN.
  Каталог открыт в изолированном браузере; ошибок нет.
- Новый сценарий Interactions проверяет 15 состояний мыши в каждой теме:
  кнопки, нажатие, иконка, карточки, первая/последняя строка, popup, dropdown,
  сегменты. Alchemist содержит **180 PNG** (90 читаемых Windows и 90 CI).
- UI-аудит содержит **154 PNG**. Меню темы проверено внутри NozeltApp при
  720×520 и 1180×760, в dark/light. Изменённые снимки просмотрены попарно;
  Android-раскладки и крупный текст проверены в тестах, не на телефоне.

Артефакты сравнения: `output/hover-review-1.0.0+37` в корне проекта.
`menu-before-after-zoom.png` сравнивает пользовательский скриншот +36 с новым
рендером реального экрана настроек. Это Flutter-рендер теста, не снимок рабочего
окна. Runtime-проверка и установка фиксируются отдельными JSON в той же папке;
golden-тесты не заменяют проверку Defender после запуска EXE.

## Windows release

Обычная release-сборка +37 прошла сканирование Defender и 301 секунду наблюдения
после запуска с изолированными данными. Готовый portable ZIP тоже просканирован
без обнаружений (сигнатуры 1.459.684.0, 13 октября 2026). Это результат текущей
локальной проверки, не гарантия решений будущих версий антивируса.

Рабочая папка `C:\Nozelt Windows Portable` обновлена
копированием только файлов из проверенного manifest; перед заменой создана
полная резервная копия. SHA-256 всех файлов portable-data после обновления
совпадают с исходными. Существующий процесс mihomo и его TUN не перезапускались.
Результат запуска установленной копии записывается отдельно в
`installed-launch-status.json` и `installed-runtime-verification.json`.
