# Добавление профилей — 1.0.0+35

## Поведение

- Над вкладками «Подписка / Ссылки / Файл» размещено действие «Из буфера». На Android рядом находится «По QR-коду». Используются общие NozeltButton и NozeltProfileImportActions; длинные подписи переносятся, кнопки сохраняют одинаковую высоту.
- Буфер читается только после нажатия. Один HTTPS URL распознаётся как подписка; поддерживаемая share-ссылка или несколько share-ссылок по строкам — как ручной профиль. Импорт выполняется сразу через существующий ProfilesNotifier. Имя, выбранное ядро и интервал обновления сохраняют значения формы.
- Пустой буфер, посторонний текст, HTTP-подписка и превышение лимитов дают локальную ошибку. Содержимое буфера/QR не включается в текст ошибок или журнал.
- Поле User-Agent удалено на обеих платформах. HTTP-заголовки по-прежнему автоматически выбирает существующий клиент подписок; совместимость сохранённых профилей не меняется.
- Подпись имени: «Название (опционально)». Убраны пояснения под полями, дублирование имени выбранного файла и автоматическая подсказка выбора ядра на этой форме.
- Для QR используется mobile_scanner 7.4.2 и встроенная Android-модель ML Kit. Разрешение камеры запрашивается только при открытии сканера; камера не обязательна для установки приложения. При фоне сканирование останавливается, после возврата возобновляется при выданном разрешении; закрытие освобождает камеру. Неподходящий QR не закрывает сканер, подходящий обрабатывается однократно.

## Файлы

- `lib/src/ui/add_profile_screen.dart` — форма и быстрый импорт.

- `lib/src/ui/profile_qr_scanner_screen.dart` — Android-сканер, lifecycle и состояния ошибки камеры.
- `lib/src/ui/widgets/profile_import_actions.dart` — общая композиция действий.
- `lib/src/l10n/nozelt_l10n.dart` — RU/EN.
- `android/app/src/main/AndroidManifest.xml` — необязательная камера и permission.
- `test/profile_*import*_test.dart`, `test/profile_qr_scanner_test.dart` — поведение.
- `test/design_system` и `widgetbook` — визуальные сценарии.

## Проверки и пределы

315 Flutter-тестов проходят, analyze без замечаний. Widgetbook: 7 тестов, analyze без замечаний, web-release собран без CDN; браузерная проверка каталога — без JavaScript-ошибок и внешних HTTP-запросов. Alchemist теперь содержит 112 PNG (56 Windows + 56 CI): добавлены быстрые действия и все три типа добавления профиля в dark/light на Windows/Android.

Отдельно проверены однократность импорта при двойном нажатии, отсутствие чтения буфера при открытии формы, отказ от загрузки постороннего текста, закрытие формы при ожидающем буфере, валидация и ограничения ссылок, QR с ошибкой/правильной ссылкой, отказ разрешения, фон/возврат и освобождение камеры. Камера в widget-тестах имитируется; реальное распознавание на физическом Android ещё нужно проверить. Телефон не подключался и APK не устанавливались.

Снимки до и после находятся в `output/profile-import-review-2026-10-13/` в корне проекта. Это рендеры настоящих Flutter-форм с тестовым engine, а не фотографии устройства.

Windows собран в release с прежними проверенными ядрами, без изменения Go/C++ и VPN-логики. Android собран как подписанные debug APK ARM64/ARMv7 для локального тестирования; production-keystore не настроен. Проверены APK-подписи, minSdk 24, версия ARM64 2035 и необязательность камеры.

Проверки Defender и окончательные хеши упаковки записываются рядом с артефактами в `output/releases/1.0.0+35/`. Сборка сама по себе не заменяет установленную portable-версию и не изменяет её настройки или рабочий TUN.

Источник API сканера и описание встроенной модели: [mobile_scanner](https://pub.dev/packages/mobile_scanner).
